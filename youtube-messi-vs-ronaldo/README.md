# 🐐 Messi vs Ronaldo — World Cup 2026 Comedy Short

A ready-to-produce YouTube Shorts package: comedy script + full SEO kit, built in the
cute **chibi cartoon** style from the previous project.

## 📁 What's inside
| File | What it is |
|------|-----------|
| `SCRIPT.md` | 50-second shot-by-shot comedy script + clean VO read + production notes |
| `SEO-PACKAGE.md` | Titles (A/B options), copy-paste description, tags, hashtags, thumbnail + posting checklist |
| `assets/` | Chibi art references (see note below) |

## 🎬 The concept
Based on the **real 2026 bracket**: Argentina (Messi) is in the Final vs Spain on
**July 19 at MetLife Stadium**, while Portugal (Ronaldo) got knocked out. The short is
the "GOAT group chat" two days before the Final — Messi flexing, Ronaldo coping. Wholesome
rivalry banter, kid-safe, monetization-friendly.

## 🖼️ Assets
The chibi images from your last project could **not** be saved into this repo — the image
CDN is blocked by this environment's network policy. They're rendered in the chat side panel
for direct download instead:
- **Chibi Argentina team** (chibi Messi #10) → used for the confetti/CTA frame.
- **Chibi Spain vs Argentina final poster** (chibi Messi + googly-eyed trophy) → the "we saved you a seat" flex.

⚠️ There was **no chibi Ronaldo** in the last project. For the couch/disguise shots you'll
need one generated in the same style (Portugal maroon #7, spiky hair) — easy to add on request.

## 🚀 How to use
1. Read `SCRIPT.md`, record/generate the voiceover from the "Clean VO" section.
2. Animate/assemble in chibi style (vertical 9:16, burn-in captions).
3. Copy title + description + tags from `SEO-PACKAGE.md`.
4. Post July 17–18, pin the GOAT-debate comment.
